The first public release of **Sonora Sound Recorder**: a desktop recorder for your microphone, your computer's sound, or both. It includes editing, five export formats and on-device transcription.

## Features

- **Recording**
  - Sources: microphone, system audio, or both, with separate level controls for each.
  - Two-source output: one combined file, separate files per source, or both.
  - Parallel recording sessions with independent settings and a clearly marked target session.
  - Live mirrored waveform, level meters, clip indicator, elapsed time, file size (marked as estimated where applicable) and free disk space.
  - Pause/resume, time markers, an optional countdown (3/5/10 s), schedules that run while Sonora is open, and optional live monitoring.
- **Safety**
  - Audio is written to disk continuously; there is no length limit and no RAM-only buffering.
  - Recordings are recovered automatically after a crash.
  - A disconnected device pauses the session and you can resume with any device.
  - Existing files are never overwritten.
- **After recording**: a full preview and edit workspace. You can trim the start and end, cut out a section, play a selection, preview edits, and choose between a new copy and replacing the original.
- **Formats**: WAV (default, 48 kHz stereo, 24-bit), MP3, FLAC, OGG Opus and M4A AAC, with quality profiles and advanced settings. Optional loudness normalization on export. FFmpeg is bundled.
- **Archive**
  - List or card view, folders, tags, favorites and notes.
  - Search across names, notes, tags and transcripts, plus filters and sorting.
  - Bulk export, move, tag and delete.
  - Drag-and-drop import with content validation, and Sonora's own trash.
- **Transcription**: runs entirely on your device with whisper.cpp, using a GGML model you choose. You get progress and can cancel, and the text is searchable.
- **Sharing**
  - Export, show in folder and copy path.
  - On macOS, the system share sheet is also available.
- **Desktop integration**
  - The close button hides Sonora to the tray and recordings continue.
  - An optional mini recording panel.
  - Optional start at sign-in.
  - Desktop notifications and in-app cards, with an "errors only" mode.
- **Interface**
  - Six languages: English, Türkçe, Deutsch, Français, 中文, Русский.
  - Light and dark themes, high contrast, interface scaling and reduced motion.
  - Full keyboard use and screen-reader announcements.
- **Updates**: Sonora checks GitHub Releases and asks before downloading or installing. Your data is always kept.

## Installation and first start

- **Windows**: run the installer; it starts with a language selection, and you can choose the installation folder. The portable file runs without installation. The files are not code-signed, so Windows SmartScreen may ask for confirmation: choose *More info → Run anyway*.
- **macOS**: open the DMG and drag Sonora to *Applications*. The app is ad-hoc signed but not notarized, so on first launch right-click → **Open**, or run `xattr -dr com.apple.quarantine "/Applications/Sonora Sound Recorder.app"`.
- **Linux**: run `chmod +x Sonora-Sound-Recorder-0.1.0-x86_64.AppImage` and then start it. Alternatively install the DEB with `sudo apt install ./sonora-sound-recorder_0.1.0_amd64.deb`.

On first start Sonora asks, in order:

1. your **language**,
2. the **recordings folder**,
3. **permissions**,
4. the default **source and input device** (microphone by default),
5. your **shortcuts**,

and then shows a **summary**.

## Default shortcuts

| Action | Key |
| --- | --- |
| Start / stop recording | **K** |
| Pause / resume | **Space** |
| Add time marker | **L** |

Shortcuts are global by default and act on the selected session. Inside Sonora, text fields never trigger them. Because global single-key shortcuts take over these keys in other apps while Sonora runs, you can switch to *Only in Sonora* or change the keys in **Settings → Shortcuts**.

## Choosing a transcription model

1. Download a whisper.cpp **GGML** model (`ggml-*.bin`, for example `ggml-base.bin`) from <https://huggingface.co/ggerganov/whisper.cpp/tree/main>.
2. Go to **Settings → Transcription → Choose model file…**. Sonora checks the file header before using it.
3. In the archive, open a recording and press **Transcribe**.

Models are never downloaded automatically, and audio never leaves your computer. GGUF, PyTorch and ONNX files are not supported.

## Known limitations

- **macOS**
  - The app is not notarized; see the installation note above.
  - System audio needs **macOS 13 or newer** and the **Screen Recording** permission. On macOS 12 only the microphone is available.
- **Windows**: the packages are not code-signed, so SmartScreen may ask for confirmation.
- **Linux/Wayland**
  - A system portal dialog asks which screen to share before system audio is captured; only the audio is recorded.
  - Global shortcuts depend on the desktop's portal support.
- **Updates**
  - The Windows installer and the AppImage update themselves after you confirm.
  - The portable version, the DMG and the DEB are downloaded and opened for you; finishing the upgrade is a manual step.
- **Schedules** run only while Sonora is running, as a window or in the tray. Schedules missed while it was closed are marked *Missed* and are never started later.
- **Transcription on x64** requires a CPU with AVX2.
- **Builds** are x64 for Windows and Linux, and arm64 plus x64 for macOS.
- **Hardware behaviors** cannot be exercised on CI runners. These are microphone and system audio capture, global shortcuts, native sharing and permission prompts; see `docs/TESTING.md` for the manual checks.
