## Security

- **Electron 44.10.0** with **Node.js 24.22.1**. This fixes the Node.js October 2026 security release, including CVE-2026-111497, an out-of-bounds write in the Brotli decoder, and the TLS and DNS hostname validation issues. It also includes the Electron fix for the compromised eMudhra intermediate certificates.
- Dependencies updated so that `npm audit` reports no known vulnerabilities:
  - zod 4.6.7 fixes memory exhaustion while validating oversized input.
  - undici and fast-uri moved to patched versions.
  - vitest 5 for the test suite.
- CI now builds with Node.js 24.22.1.

## Design

- **New display typeface: Instrument Serif.** It is used for page titles, the recording clock, dialog and onboarding headlines; interface text stays in Inter. Russian and Chinese use Inter for headlines as well, because the serif has no Cyrillic or Chinese glyphs.
- **Calmer recorder.**
  - A large serif clock with fixed-width digits, so it never shifts while counting.
  - Format, size, markers and free space sit in one small line under the record button.
  - Explanatory sentences, page subtitles and repeated hints were removed throughout the app.
- **Adjustable side panel.**
  - Drag the edge to make the panel on the record page wider or narrower, or double-click it to reset.
  - Hide or show the panel with one button, and collapse each card (levels, source, output, schedules) separately.
  - The layout is remembered.
- **Animated first start and update dialog.**
  - First start: serif headlines, steps that enter one after another, and a living sound-wave motif.
  - Update dialog: the version change is shown large, and the wave fills up as the download progresses.
- **Branded Windows installer.** The installer has its own sidebar and header artwork.

## Fixed

- **Session names now follow the language.** The automatic name of a session, such as "Session 1", appeared in English even when the interface was in another language. It is now translated in all six languages and changes with the language. Names you chose yourself are never touched.

## New

- **Terms of Use and Privacy Policy** in all six languages:
  - accepted once during the first start, or once after updating;
  - always available under **Settings → About**, together with the version, licence, source code and third-party licences.
- **Mini panel shortcuts setting.** **Settings → Shortcuts → Also in the mini panel** decides whether the mini panel handles K, Space and L itself while it has focus. It is on by default.

## Faster and lighter

- Live waveform and level meters share a single animation loop. It draws only when new audio arrives and stops completely while nothing is captured or while the window is hidden in the tray or minimized. The waveform is drawn in one pass instead of one shape per bar.
- The recording screen re-renders once per second instead of five times, and the side panel no longer re-renders with the clock.
- Faster start:
  - The window opens without waiting for the installer language lookup, the transcript search index or the check for missing files; these run in the background.
  - A healthy archive file is no longer rewritten on every start, and the archive is stored compactly.
- Pages load on first use and are prepared in the background. The mini panel loads only its own code.
- During a recording, the recording manifest is rewritten only when it actually changes, not every two seconds. Audio is still flushed to disk on the same schedule.
- The log writer no longer checks the file size on disk for every line, and the tray icon is updated only when recording starts or stops.
- Long archives animate fewer elements and re-render only the entries that change.

## Known limitations

These are unchanged from 0.1.1:

- The packages are not code-signed or notarized.
- System audio on macOS needs version 13 or newer and the Screen Recording permission.
- Real microphones, system audio and global shortcuts are not available on CI runners. See `docs/TESTING.md` for the manual checks.
